# Poker RPG — Privacy Policy

This public repository hosts the **Poker RPG** Privacy Policy for **SagaForge Interactive**.

- Site source: [index.html](./index.html)
- GitHub Pages URL (once enabled): https://istelmah.github.io/poker-rpg-privacy/

## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then click **Save**.
4. Open the published HTTPS URL in an incognito window to confirm the policy is public before adding it to Google Play Console.

## Important

Keep the Google Play **Data Safety** declaration and in-app Privacy Policy link consistent with the actual release build. The Android QA analytics endpoint in the game's private development repository must be replaced or disabled before external release.
